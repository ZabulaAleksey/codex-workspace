# Каталог проектов

## Активный основной набор

1. **Trading Terminal** — терминал для исследования и тестирования стратегий, Monte Carlo, оптимизация, мост с MT.
2. **Music Sequencer** — музыкальный секвенсер, DSP, обработка звука в реальном времени.
3. **Field Lab** — вычисление и визуализация математических и электромагнитных полей; потенциально часть образовательной платформы.
4. **Tutor Platform** — сайт или приложение репетитора: материалы, доска, WebRTC, Yjs, календарь, вызовы и уведомления на смартфоне.
5. **WiFi Share** — передача файлов внутри локальной сети.
6. **Receipt Price DB** — OCR чеков, нормализация товаров, история цен.
7. **Video Chronicle** — нормализация фотографий и видео, временные метки и сборка единого MP4 через FFmpeg.
8. **Text Recognition Core** — переиспользуемое offline-first ядро OCR/HTR, исправлений и revisions для Personal Chronicle, Receipt Scanner, Tutor и будущих consumers; сейчас создан КАРКАС, реализация не начата.
9. **AI Dev Team** — этот метапроект: общие агенты, skills, hooks, rules, MCP и в будущем программный оркестратор.

## Ранее обсуждавшиеся кандидаты и вспомогательные проекты

Стоит решить, остаются ли они активными:

- **Инструменты для блокчейна и криптовалют** — исследование блоков, транзакций, кошельков и контрактов, инструменты testnet.
- **Цифровой двойник инвертора DEYE** — цифровой двойник фотоэлектрической системы, аккумулятора и инвертора, Modbus/RS485/Wi‑Fi, MATLAB/Simulink или Python.
- **ИИ-бот для Dune 2** — распознавание состояния игры и управление ботом.

- **Контуры Фурье и вращающиеся векторы** — можно объединить с Field Lab как модуль гармонического анализа.
- **Небольшое приложение React для финансов и доходов** — скорее учебный или архивный проект, чем отдельная долгосрочная платформа.
- **Решатель японских кроссвордов по изображению** — отдельный учебный проект компьютерного зрения и алгоритмов, если он всё ещё нужен.
- **Низкоуровневые эксперименты и ОС** — отдельная учебная ветка для системного программирования.
- **MCP для Mathcad** — логичнее считать инфраструктурным интеграционным проектом или плагином, а не самостоятельным продуктом.

## Идеи, хорошо дополняющие текущую экосистему

### Общее научное ядро

Общий пакет на Rust/Python для численных вычислений, который смогут использовать Trading Terminal, Field Lab и часть Tutor Platform.

### Персональная платформа данных

Единый локальный слой данных и аналитики для чеков, финансов и других личных наборов данных: Arrow, Parquet и DuckDB.

### Общее ядро совместной работы в реальном времени

Пакет примитивов Yjs/WebRTC, пригодный для Tutor Platform и Music Sequencer.

### Общая лаборатория наблюдаемости

Один набор docker-compose с OpenTelemetry Collector, Grafana, Tempo и Prometheus для практики наблюдаемости во всех серверных проектах.
