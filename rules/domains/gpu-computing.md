# GPU-вычисления

- Определи CPU reference и числовые допуски до оптимизации.
- Учитывай передачу данных, синхронизацию, размер batch и ограничения памяти.
- Проверяй ошибки kernel и корректность fallback.
- Benchmark должен включать прогрев и одинаковые входные данные.
- Сравнивай end-to-end latency, а не только время kernel.
- Не заявляй ускорение без воспроизводимых результатов до и после.
