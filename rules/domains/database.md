# Базы данных

- Модель данных должна отражать инварианты SPEC.
- Для изменения схемы определи миграцию, совместимость и путь восстановления.
- Избегай необратимых операций без резервной стратегии.
- Проверяй транзакционные границы, конкурентность и уникальность.
- Анализируй планы запросов для критичных путей.
- Не помещай секреты или чувствительные данные в логи.
