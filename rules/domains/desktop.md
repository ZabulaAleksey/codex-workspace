# Desktop

- Не блокируй UI-поток длительными операциями.
- Определи жизненный цикл окон, фоновых задач и отмены.
- Учитывай файловые диалоги, разрешения и платформенные пути.

- Ошибки должны быть понятны пользователю и пригодны для диагностики.
