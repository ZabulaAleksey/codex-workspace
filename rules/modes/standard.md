# Стандартный production-режим

Используй для обычной разработки новой функции, исправления поведения или изменения одной подсистемы.

- Для новой существенной функциональности SPEC обязательна.
- Сначала определи критерии приёмки и затрагиваемые контракты.
- Реализация должна соответствовать архитектуре, дизайну и решениям проекта.
- Изменённое поведение должно быть покрыто тестом либо иметь зафиксированное объяснение, почему автоматический тест неприменим.
- После реализации выполни проверку соответствия SPEC.
- Не расширяй область задачи без явной необходимости.
