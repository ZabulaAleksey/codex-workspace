# Этап дизайна

- Сначала прочитай SPEC и `docs/DESIGN.md`.
- Определи пользовательские сценарии, состояния loading/empty/error и responsive-поведение.
- Учитывай accessibility, клавиатурную навигацию и понятную обратную связь.
- Используй существующие tokens и компоненты до создания новых.
- Свяжи важные UI-состояния с критериями приёмки SPEC.
- Не меняй утверждённое поведение только ради визуального упрощения.
