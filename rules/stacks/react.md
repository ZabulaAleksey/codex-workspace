# React

- Храни состояние на минимально необходимом уровне.
- Не используй effect для вычислений, которые можно выполнить при render.
- Компоненты должны иметь явные loading/error/empty-состояния.
- Стабилизируй ключи списков и очищай подписки.
- Тестируй поведение пользователя, а не внутренние детали компонента.
