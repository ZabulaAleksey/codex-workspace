# TypeScript

- Не ослабляй типизацию через `any` без локальной причины.
- Валидируй внешние данные во время выполнения.
- Используй discriminated unions для состояний и результатов.
- Не дублируй серверные и клиентские контракты вручную без необходимости.
- Проверяй typecheck отдельно от unit-тестов.
