# Маршрутизатор правил стека

Выбирай только фактически используемые технологии. Храни здесь конкретные ограничения стека, например правила ABI, владения ресурсами, типов, миграций или инструментов сборки.

Не копируй универсальные style guides и не загружай правила технологий, которых нет в проекте.
