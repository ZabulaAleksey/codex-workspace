# FastAPI

- HTTP handlers должны оркестрировать, а не содержать бизнес-логику.
- Используй модели запросов и ответов с явной валидацией.
- Корректно управляй async-вызовами и блокирующей работой.
- Определи стабильные HTTP-коды и схему ошибок.
- Зависимости авторизации проверяй на каждом защищённом маршруте.
