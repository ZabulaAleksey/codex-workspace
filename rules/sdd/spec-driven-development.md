# Разработка на основе спецификаций

## Основной принцип

Для существенного программного поведения SPEC является каноническим описанием ожидаемого поведения системы.

- Код не является источником требований.
- Тесты не являются источником требований.
- Prompt агента не является источником требований.
- Архитектура описывает устройство решения, а не заменяет требования.

Если эти источники противоречат SPEC, сначала определи и явно опиши причину расхождения.

## Цепочка от требования к коду

Для `STANDARD` и `COMPLEX` функциональности используй:

```text
Намерение пользователя
    ↓
Требования
    ↓
SPEC
    ↓
Архитектура
    ↓
План реализации
    ↓
Код
    ↓
Тесты
    ↓
Проверка соответствия SPEC
```

Не перескакивай непосредственно от запроса пользователя к коду, если задача меняет существенное наблюдаемое поведение продукта.

## Перед реализацией

1. Найди соответствующую SPEC через `specs/README.md`.
2. Прочитай только затрагиваемую системную или feature-SPEC.
3. Определи требования, критерии приёмки и открытые вопросы.
4. Проверь связанные `ARCHITECTURE.md`, `DESIGN.md`, `DECISIONS.md` и `SECURITY.md`, если они относятся к задаче.
5. Если SPEC отсутствует:
   - для `SIMPLE` допустима краткая inline-spec;
   - для `STANDARD` создай или обнови SPEC до реализации новой функции;
   - для `COMPLEX` полная SPEC обязательна до существенной реализации.

## Во время реализации

Не меняй ожидаемое поведение молча. Если реализация требует изменения требований:

1. останови изменение спорного поведения;
2. опиши конфликт;
3. обнови SPEC после согласования;
4. при необходимости зафиксируй решение в `DECISIONS.md`;
5. затем измени реализацию.

## После реализации

Проверь цепочку:

```text
SPEC → критерии приёмки → тесты → реализация
```

Каждое обязательное требование должно быть реализовано, проверяемо и протестировано либо иметь объяснение отсутствия автоматического теста.

Задача не завершена полностью, если реализация противоречит SPEC, критерии приёмки не проверены, SPEC устарела или появилось незадокументированное изменение поведения.
