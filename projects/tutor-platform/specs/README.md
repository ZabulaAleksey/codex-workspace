# Индекс спецификаций Tutor Platform

- `system.spec.md` — общие границы и системные требования.
- `features/<feature>.spec.md` — требования отдельной существенной функции; создаются по мере необходимости.

| SPEC | Статус | Назначение |
|---|---|---|
| `system.spec.md` | Черновик | Базовая системная спецификация preset |

Используй идентификаторы `FR-###`, `NFR-###`, `SEC-###`, `PERF-###` и `AC-###`. Prompt этапа должен ссылаться на SPEC, а не дублировать её требования.
