---
name: resume-project
description: Resume work in an existing repository by reading AI_STATUS/ROADMAP and selecting the smallest justified next task.
---

1. Read `docs/AI_STATUS.md`, `docs/ROADMAP.md`, `docs/ARCHITECTURE.md`, and recent git status/diff.
2. Use built-in `explorer` only if the status files are insufficient.
3. State the current stage, what is already complete, blockers, and the single best next task.
4. Do not implement unless the user asked to continue implementation.
5. If implementation was requested, hand off to `$implement-stage`.
