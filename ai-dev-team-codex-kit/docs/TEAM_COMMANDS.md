# Команды и формулировки для AI-команды

## Посмотреть состояние проекта

```text
$resume-project
```

или:

```text
Прочитай AI_STATUS и ROADMAP. Скажи, на каком мы этапе и какой следующий минимальный шаг. Ничего не меняй.
```

## Спланировать этап

```text
$plan-stage
Спланируй этап 4. Используй architect + explorer и профильного специалиста. Ничего не реализуй.
```

## Реализовать этап

```text
$implement-stage
Реализуй текущий AI_PLAN. Параллельные write-agents должны владеть непересекающимися файлами. После тестов вызови reviewer.
```

## Явно вызвать конкретных субагентов

```text
Параллельно запусти architect и explorer. Дождись обоих. Затем передай backend/** backend_engineer, а frontend/** frontend_engineer. После их завершения запусти test_engineer и reviewer.
```

## Исследовать технологию

```text
Используй docs_researcher. Проверь актуальную официальную документацию <technology>, совместимость с нашим стеком и предложи минимальный spike. Не добавляй dependency.
```

## Проверить изменение

```text
$review-change
```

## Объяснить сделанное

```text
$explain-change
```

## Субагенты в интерфейсе Codex

- `/agent` — посмотреть/переключаться между потоками субагентов.
- `/skills` или `$skill-name` — выбрать skill.
- `/hooks` — проверить и доверить hook definitions.
- `/mcp` — посмотреть MCP в интерактивном клиенте; `codex mcp list` — из shell.
